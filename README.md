# PrefixTitles 1.2.0 — Paper 1.21.11

Плагин позволяет игрокам самостоятельно создавать и оформлять личный префикс и титул.

## Возможности для игроков

- Свой префикс перед ником и свой титул после ника.
- Цвета из палитры и произвольный HEX (`#RRGGBB`).
- Градиент из двух цветов.
- Жирный, курсив, подчёркивание, зачёркивание и обфускация текста.
- Три дополнительных встроенных шрифта Minecraft: `Uniform`, `Alt` (алфавит зачарований) и `Illageralt`.
- Меню символов и эмодзи, выбранных из набора, рассчитанного на отображение стандартным шрифтом Minecraft без обязательного ресурспака.
- Предпросмотр ника, сохранение собственных настроек и возможность снять/удалить свой вариант.
- Отображение оформления в чате; префикс/титул над головой и в списке TAB — при условии, что эти scoreboard-команды не заняты другим плагином.

**Важно о шрифтах и эмодзи:** `Alt` и `Illageralt` рассчитаны в основном на латиницу/цифры, поэтому для кириллицы редактор оставляет доступными обычный шрифт и `Uniform`. Ванильный Minecraft не отображает все цветные Unicode-эмодзи; меню содержит поддерживаемые символы, а не обещает отображение любого символа с телефона.

## Установка

1. Используйте Paper или совместимый форк Paper для Minecraft 1.21.11.
2. Установите Java 21.
3. Поместите `PrefixTitles-Paper-1.2.0.jar` в папку `plugins`.
4. Перезапустите сервер. Данные появятся в `plugins/PrefixTitles/prefixtitles.json`.

Плагин использует Paper API и **не является модом для Fabric/Forge/NeoForge**. На этих ядрах он напрямую не запускается. Если другой плагин (например, TAB/nametag-плагин) управляет scoreboard-командами, PrefixTitles не перезаписывает их: чат продолжает показывать оформление, но отображение над головой и в TAB может потребовать интеграции с тем плагином.

## Команды

- `/pt` — главное меню.
- `/pt custom prefix` — редактор своего префикса.
- `/pt custom title` — редактор своего титула.
- `/pt clear` — снять активные префикс и титул.
- `/pt cancel` — отменить текущий ввод в чат.
- `/pt admin` — админ-панель.
- `/pt resetcustom <игрок> [prefix|title|all]` — сбросить пользовательские записи игрока.
- `/pt reload` — перечитать JSON-файл.

## Права

| Право | По умолчанию | Назначение |
|---|---:|---|
| `prefixtitles.use` | everyone | Использование `/pt` |
| `prefixtitles.admin` | op | Админ-панель и админ-команды |
| `prefixtitles.custom` | everyone | Создание своих записей |
| `prefixtitles.custom.color` | everyone | Цветовая палитра |
| `prefixtitles.custom.hex` | everyone | HEX-цвета |
| `prefixtitles.custom.gradient` | everyone | Градиент |
| `prefixtitles.custom.bold` | everyone | Жирный |
| `prefixtitles.custom.italic` | everyone | Курсив |
| `prefixtitles.custom.underline` | everyone | Подчёркивание |
| `prefixtitles.custom.strikethrough` | everyone | Зачёркивание |
| `prefixtitles.custom.obfuscated` | op | Обфускация |
| `prefixtitles.custom.font` | everyone | Выбор шрифта |
| `prefixtitles.custom.emoji` | everyone | Символы/эмодзи из меню |
| `prefixtitles.custom.bypass` | op | Обход фильтра запрещённых слов |

Права можно менять через LuckPerms. Для выдачи доступа к ограниченной админом записи используются `/pt grant` и `/pt revoke`.

## Настройки и защита

Основной файл — `plugins/PrefixTitles/prefixtitles.json`.

- `customMaxLength` — максимальная длина личного текста (по умолчанию 16 символов).
- `blockedWords` — запрещённые слова для пользовательских префиксов и титулов.
- `prefixSpacer` и `titleSpacer` — пробелы между префиксом/ником/титулом.

Игроки не могут использовать legacy-коды форматирования в своём тексте: оформление включается через меню. Текст проверяется на пустоту, длину, недопустимые символы и запрещённые слова.

## Сборка из исходников

Нужны JDK 21 и Maven. В корне проекта выполните:

```bash
mvn clean package
```

Готовый файл: `target/PrefixTitles-Paper-1.2.0.jar`.
